# gongwen-format

中文公文格式校验 Skill：基于 GB/T 9704—2012《党政机关公文格式》整理规则摘要，辅助检查公文的主体结构、字体、层级、附件、落款、页码及 DOCX 版式问题。

> **注意**：这是一份社区维护的辅助检查规则，**不是**国家标准原文、官方认证产品，也不能替代机关正式模板、人工校对或签发审批。请核对适用的现行规范。对于不能读取和渲染 DOCX/PDF 的运行环境，Skill 只能提供文本层检查与待确认项。

## 功能范围

- 区分**通用公文格式**与**信函格式**，避免将“函”文种直接等同于信函首页版式。
- 对标题、主送机关、正文、层级序号、附件说明、署名、成文日期及页码进行检查。
- 区分**国家标准明示要求**、**一般排版惯例**与**单位模板约定**。
- 在具备本地文件处理能力的运行环境中，参考 DOCX/OOXML 核验清单开展程序化修复与落盘验证。
- 保留**必须人工逐页复核**的环节：实际分页、印章、首页页码、字体替代效果与红色双线。

## 安装和使用

### WorkBuddy（本地）

将本仓库克隆或下载后，复制 `gongwen-format` 文件夹到用户的 Skill 目录（典型 Windows 路径如下；实际目录以你的 WorkBuddy 版本为准）：

```text
%USERPROFILE%\.workbuddy\skills\gongwen-format\
```

重新开始会话，并附上 DOCX 文档，输入：

> 请使用 gongwen-format Skill 检查这份函件格式。先判断适用的版式类别，再输出位置、问题、依据、修改建议及需要人工确认的项目。

能否自动修改 DOCX，取决于你的客户端是否具有可用的本地文档操作、DOCX/OOXML 编辑及渲染能力；**安装本 Skill 本身不会自动安装这些能力**。

### HiAgent、Claude、ChatGPT 或其他平台

将 [`SKILL.md`](SKILL.md) 作为自定义指令或智能体的主规则，将 `references/` 下的 Markdown 文件加入知识库或相关 Skill 资源目录。若平台不提供文件操作功能，则仅用作文本层格式检查，**不要宣称已经验证字号、页码、分页或印章位置**。

## 验收建议

用无附件函、带附件函、多页信函各至少一份进行对照检查。文件定稿前务必在 Word/WPS 或 PDF 中**逐页目视确认**，尤其检查首页页码、奇偶页码、附件起始页、红双线及印章位置。
