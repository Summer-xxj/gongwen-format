# HiAgent 适配建议

## 推荐配置

- 将 `SKILL.md` 作为 Skill 的主指令；将 `references/format-rules.md` 和 `references/checklist.md` 放入可检索知识库，或合并进平台支持的 Skill 资源包。确保主指令中的文件名/知识条目名称与实际导入名称一致。
- 如 HiAgent 不支持文件引用，保留核心边界、类型识别、首行缩进、附件、落款及页码判断在主提示词中；把详细条款放知识库，按需召回。
- 上传正式 GB/T 9704—2012 PDF（若已有合法/内部授权文件）作为标准源；把已获授权的历史函件标成“历史样本/格式参考”，不能和规范文件混为同等权威。项目不附带内部函件或国标 PDF；部署前请自行上传有权使用的资料。
- 有经确认的单位 Word 模板时，单独命名为“本单位函件模板/实现规则”，声明它用于 DOCX 落版；若与国标表述不同，Skill 应列差异，按用户明确的机关要求执行。

## 推荐工作流分层

1. **内容输入**：由内容撰写流程提供定稿主体和必要元数据；格式 Skill 不生成地区内容。
2. **格式检查**：将文本及版式类型、模板信息交给本 Skill，返回问题表和需补字段。
3. **DOCX 落版**：通过模板填充或文档处理组件设定段落样式、分页、分节和页码。
4. **渲染复核**：导出 PDF/页面预览，复核实际缩进、换页、页码、附件、印章区域；修复后再交付。

提示词可以规定生成内容的目标格式，却不能可靠控制 Word 的版心、分页、字体替代、分节、首页页码开关和印章图层。若 HiAgent 目前只产出文本，应把输出标为“待套模板”，不能称为已通过 DOCX 版式校验。

## 建议的调用输入字段

```text
文种：函
首页版式：信函格式 / 通用格式 / 待确认
正文：……
主送机关：……
发文机关署名：……
成文日期：……
盖章方式：盖章 / 不盖章 / 待确认
附件：无 / 附件名称及顺序
Word 模板：模板名称或未提供
校验范围：红头以下主体 / 全文
```

## 建议输出字段

```text
版式判断：……
校验结论：通过 / 有条件通过 / 需修改
问题清单：位置、问题、依据性质、修改建议
待补信息：……
DOCX/PDF 实际核验：已完成 / 未完成及原因
```

## 上线前验证

用至少一个无附件函、一个带附件函及一个多页信函模板做人工对照；专门确认信函首页页码隐藏、续页页码按已批准模板显示/处理。验证目的是确认 HiAgent 检索与文档工具实际行为，不是用提示词替代模板或 PDF 渲染。
